# DAEDALUS — Site officiel

Site vitrine statique du studio DAEDALUS, hébergé gratuitement sur GitHub Pages.

## Adresse

https://yoanncontreras-lab.github.io/DAEDALUS-lab.github.io/

Le site sera accessible à cette adresse **après activation de GitHub Pages** dans les paramètres du dépôt.

## Activer la publication

1. Ouvrir https://github.com/yoanncontreras-lab/DAEDALUS-lab.github.io/settings/pages
2. Dans **Build and deployment**, sélectionner **Deploy from a branch**.
3. Choisir **main** et **/(root)**, puis cliquer sur **Save**.
4. Vérifier l'adresse ci-dessus après le déploiement.

## Structure

- index.html — Accueil
- spectralab.html — SpectraLab
- contact.html — Coordonnées et assistance
- mentions-legales.html — Mentions légales
- confidentialite.html — Confidentialité du site
- assets/ — Design et ressources du site
- config.js — Coordonnées communes

## Informations de publication

Le dépôt GitHub est public : les informations de contact, y compris l'adresse de domiciliation et le numéro de téléphone renseignés dans config.js, deviennent accessibles à tous. Vérifier les mentions légales, la conformité des coordonnées et leur diffusion avant d'utiliser le site comme référence officielle.

La politique de confidentialité de ce site ne remplace **pas** celle de SpectraLab ou d'autres applications.

Le dépôt ne contient pas les fichiers sources des applications.
